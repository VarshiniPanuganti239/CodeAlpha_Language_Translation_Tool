# AI Language Translation Tool

## Project Overview

This project is an AI-powered multilingual language translation tool developed as part of the CodeAlpha Artificial Intelligence Internship.

## Features

- Automatic Language Detection
- Multilingual Translation
- Translation History
- CSV Export
- Streamlit Web Interface
- Real-Time Translation

## Technologies Used

- Python
- Streamlit
- Deep Translator
- LangDetect
- Pandas

## Supported Languages

- English
- French
- German
- Spanish
- Hindi
- Telugu
- Tamil
- Japanese
- Korean
- Chinese
